# Sample camera model

AntiqueCamera by Maximillan Kamps / UX3D (2018), CC0-1.0.

Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/AntiqueCamera

Optimized with glTF Transform 4.5.1: 1024px WebP textures, no geometry simplification. This is a stand-in demo asset, not geometry for the dummy Volt 35mm SLR listing.

The story view uses camera-body.glb (775,232 bytes), a derivative with the separate tripod removed. The full optimized sample, antique-camera.glb (1,291,800 bytes), is kept for the optional model fallback. Both remain CC0 sample assets, not the exact dummy listing photo.
